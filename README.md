# ☕ Java Basics Practice

This repository contains my **Java practice work** where I explored the **core fundamentals of Java programming**. The focus of this project is to understand syntax, logic building, and problem-solving using Java.

---

## 📚 Topics Covered

### 1️⃣ Variables

I learned how to declare and use different types of variables in Java:

* `int`
* `float`
* `double`
* `char`
* `boolean`
* `String`

Examples include storing numbers, characters, and text values.

---

### 2️⃣ Operators

I practiced various operators used in Java:

* **Arithmetic Operators**: `+`, `-`, `*`, `/`, `%`
* **Relational Operators**: `>`, `<`, `>=`, `<=`, `==`, `!=`
* **Logical Operators**: `&&`, `||`, `!`
* **Assignment Operators**: `=`, `+=`, `-=`, `*=`, `/=`

These operators helped me perform calculations and logical decision-making.

---

### 3️⃣ Loops

I worked with different looping statements to repeat tasks efficiently:

* `for` loop
* `while` loop
* `do-while` loop

Loops were used for number iteration, condition-based execution, and pattern generation.

---

### 4️⃣ Pattern Programs

I created multiple **pattern programs** using loops, which helped me improve my logical thinking.

Examples of patterns:

* Star (`*`) patterns
* Number patterns
* Right triangle and pyramid patterns

These programs mainly use **nested loops**.
